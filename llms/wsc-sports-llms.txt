# WSC Sports Experiences

> Experiences is a mobile-first SDK from WSC Sports. It embeds Stories, Moments, and Videos in iOS, Android, Web, React Native, and Flutter apps. Content is created and scheduled in Arena (the CMS). This index is the map for coding agents.

How to use this site:

- Append `.md` to any docs URL to get markdown. Example: `https://dev.wsc-sports.com/docs/ios-sdk-integration.md`.
- Fetch a section `llms.txt` next, not every page.
- Start in Concepts for the product model. Those pages explain the idea, then link to the matching SDK reference pages for iOS, Android, Web, React Native, and Flutter. After that, open the SDK section for the framework you are implementing.
- In code and APIs the product still uses Blaze names (`BlazeSDK`, `BlazeDataSourceType`). In docs, call the product **Experiences SDK**.
- **Viewer** means the person watching content. **User** means someone in the WSC Sports console.
- For live API search inside an editor, connect the Experiences MCP servers: https://dev.wsc-sports.com/docs/experiences-mcp.md
